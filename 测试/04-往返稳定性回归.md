# 04 往返稳定性回归

> **本文档是"每次保存文件不该变大"的专项回归用例。**
> 每一节都对应一个已修复的缺陷,请按 [4.5 验证步骤](#45-验证步骤) 复验。

## 4.1 脱字符 `^`(回归:转义集合不对称)

正文里的脱字符必须能原样往返,不得累积反斜杠。

- 行中:a^b · 2^10^ · x^2
- 行尾:结尾是 ^
- 连续:^^ 与 a^^b
- 与其它标记混合:**粗体^内** · `代码^内` · ==高亮^内==

^以脱字符开头的段落(块首位置,不得被转义)

**预期**:第 2 行到第 5 行在多次保存后**不出现反斜杠**;渲染结果与首次打开一致。
(修复前:`a^b` 每保存一次多两个反斜杠,永不收敛。)

## 4.2 表格单元格(回归:双重转义导致指数膨胀)

| 类型 | 内容 | 备注 |
| --- | --- | --- |
| 括号 | Tauri v2 (Rust) | 普通文本里的圆括号 |
| 方括号 | arr[0] 与 [链接](https://example.com) | 方括号与链接 |
| 公式 | $\frac{a}{b}$ | KaTeX 源码含反斜杠 |
| 公式二 | $$\sum_{i=1}^{n} i^2$$ | 与 `$$` 同行 |
| 行内代码 | `a\b` | 代码内单个反斜杠 |
| 行内代码二 | `C:\Users\me` | Windows 路径 |
| 行内代码三 | `\d+\s*` | 正则 |
| 行内代码四 | `a\|b` | 代码内的转义管道符 |
| 行内代码五 | `**不是粗体**` | 代码内的 Markdown 语法 |
| 纯文本管道符 | a\|b | 单元格内的转义管道符 |
| 反斜杠组合 | `\\server\share` | 双反斜杠 |
| 空单元格 |  | 右侧为空 |

**预期**:
1. 所有单元格渲染正确,**公式能正常渲染**(修复前公式源码会被反斜杠破坏);
2. 多次保存后表格内容**逐字不变**,不再出现"反斜杠越积越多"的现象(修复前括号会被写成 `\` + `(` 并逐轮翻倍)。

## 4.3 HTML 块段落(回归:漏掉硬换行折叠)

<p align="center">
  Made with love by Qiao-zhihang
</p>

<div class="note">
  第一行内容
  第二行内容
  第三行内容
</div>

<div align="center">单行 HTML 块</div>

**预期**:三次保存之后,上述 HTML 内部**不得出现多余的行尾空格**(修复前每个换行每轮 +2 个空格)。
渲染后三块内容外观不变。

## 4.4 一次性归一化(正常行为,不是缺陷)

下面这些在**第一次保存**时会发生变化,之后保持不变:

1. 无对齐标记的表格会被补全为显式左对齐:

| 列一 | 列二 |
| --- | --- |
| a | b |

2. 无语言的围栏会被补上 `plaintext`(见 [03-表格与代码块.md](./03-表格与代码块.md) 中的无语言围栏);

3. 行首的 `<` 会被转义为 `\<`(避免被当成 HTML 块起始)。

4. 行内代码里的"反斜杠 + 标点"会被**还原一级**——这是为修复老文档污染而做的兼容取舍
   (老版本会把 `` `a_b` `` 写成 `` `a\_b` ``)。下面用围栏展示对照(围栏内不受影响,故本文档仍然稳定):

```
`\*`   →   `*`
`\(`   →   `(`
`\.`   →   `.`
`\[0\]` →  `[0]`

C:\Users\me   →  不变(反斜杠后是字母)
\d+\s*        →  不变(反斜杠后是字母)
```

   注意:因此"反斜杠 + 标点"的行内代码**每打开一次会再还原一级**,多级反斜杠会逐级消失;
   而"反斜杠 + 字母/数字"完全不受影响(Windows 路径、正则都安全)。

**预期**:前三处只变一次;第四处按上述规则逐级还原到没有"反斜杠+标点"为止;之后文件内容逐字相同。

## 4.5 验证步骤

### 手动(推荐,2 分钟)

1. 记录本文档的文件大小(资源管理器看属性,或 `dir 测试\04-往返稳定性回归.md`);
2. 在编辑器里打开 → 直接保存(Ctrl+S)→ 关闭标签页;
3. 重新打开 → 再保存 → 关闭(重复 2~3 次);
4. 比较文件大小:第 2 次保存之后**应完全不再变化**。

修复前的现象:每保存一轮都变大(实测一份 6.2KB 文档 4 轮增长 +136 字符且不收敛)。

### 自动(CI 可跑)

```bash
node scripts/ai-render-tests/run.mjs
```

第 15 组「往返稳定性」会断言:
- 逐字符(含 `^`)在行中 / 块首位置多轮往返恒等;
- 表格的括号 / 公式 / 代码反斜杠 / 管道符四类单元格恒等;
- HTML 块段落恒等且无多余行尾空格;
- 本目录下所有 `*.md` 文件:多轮往返**收敛且不再变大**(历史转义如 `\(` 需 1~2 轮还原,属有意兼容行为),且渲染不抛异常。
