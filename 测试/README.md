每个文件末尾/开头都标注了「预期」,方便逐项对照。

## 怎么用

1. 打开本仓库(vault)所在目录;
2. 用编辑器打开 `测试/` 下的任一文件,按文中「预期」逐项核对;
3. 对 `04-往返稳定性回归.md`,按下文步骤做**保存往返**验证。

## 自动化检查

本项目已有一套零依赖的纯函数测试台(**当前 143 项**),其中第 15、16 组就是往返稳定性与本文档集的校验:

```bash
node scripts/ai-render-tests/run.mjs
```

它会:
- 对 `测试/*.md` 逐个执行「反序列化 → 序列化」多轮循环,断言**收敛且不再变大**(反复保存不会让文件膨胀;历史转义如 `\(` 需要 1~2 轮才还原到规范形态,属有意兼容行为);
- 断言渲染器不抛异常,且渲染结果里不含**可执行形态**的标签/属性(如真正的 `<script>` 标签、`on*` 事件属性、`javascript:` 协议属性);
- 校验逐字符转义对称性、表格/HTML 块等具体回归点。

> 该检查不依赖浏览器,可在 CI 中作为门禁(需在仓库根目录运行)。

## 已知限制(不是 bug,已在用例中标注)

| 现象 | 说明 |
| --- | --- |
| 块级公式必须与 `$$` 同行 | `$$` 单独成行、公式跨行时不解析(编辑器与 AI 气泡一致) |
| 脚注 `[^1]` | **仅 AI 气泡支持**;文档编辑器里按字面文本显示 |
| 代码高亮 | 未实现(零依赖方案下暂缓),代码块只有语言标签与底色 |
| 表格 `\| --- \|` → `\| :--- \|` | 首次保存会补全对齐标记,属一次性归一化,之后稳定 |
| 无语言围栏 ` ``` ` → ` ```plaintext ` | 首次保存补全语言名,一次性 |
| 行内代码内 `\*` 这类转义 | 会被还原为字面 `*`(与历史渲染行为一致);`\` + 字母/数字(如 `C:\Users`、`\d+`)原样保留。多级"反斜杠+标点"会**每打开一次还原一级**,详见 [04-往返稳定性回归.md](./04-往返稳定性回归.md) §4.4 |
