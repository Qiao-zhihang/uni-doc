# 05 AI 气泡验收

> AI 气泡渲染的是**模型回复**,不是文档内容,所以本文件提供两样东西:
> ① 一段可复制的**提问模板**(让模型输出覆盖全部特性的回答);② 期望结果清单。

## 5.1 提问模板(复制 fenced 块内的全文,发给 UU鲨)

```text
请用一份 Markdown 回复演示下列全部语法,每一项都必须出现,并用二级标题分节。
除 Mermaid 那一项外,不要用代码围栏包裹这些语法本身。

1. 行内数学 $E=mc^2$ 与 $\frac{a}{b}$;块级数学 $$\int_0^1 x^2\,\mathrm{d}x = \frac{1}{3}$$($$ 必须与公式写在同一行)
2. 一张 Mermaid 流程图,用 ```mermaid 围栏,节点标签里包含 <br/> 换行
3. 一张 Markdown 表格:表头 3 列;单元格里分别放 (圆括号)、$\frac{1}{2}$、`a\b`、`a|b`
4. ==高亮==、x^2^(上标)、H~2~O(下标)、<u>下划线</u>
5. 原始 HTML:<p align="center">居中文本</p> 与 <kbd>Ctrl</kbd>+<kbd>C</kbd> 与 <mark>mark 高亮</mark>
6. 脚注:正文里写 引用[^1],文末写 [^1]: 这是脚注定义
7. 一个三层嵌套列表、一个任务列表(- [x] / - [ ])
8. 行内代码里包含 Markdown 语法:`**不是粗体**`、`arr[0]`、`if (x) < y`、`C:\Users\me`
9. 一张图片:![示意图](assets/测试图片.png)

不要省略任何一项。
```

## 5.3 流式输出期间的预期(设计如此,不是 bug)

| 现象 | 说明 |
| --- | --- |
| 打字过程中公式显示为 `$E=mc^2$` 字面 | 流式期间用轻量渲染器(容错优先),收到完整回答后才切换为完整渲染 |
| 打字过程中 Mermaid 显示为代码块 | 图表只在回答结束后渲染,避免每来一个字都重画一张图 |
| 打字过程中图片显示为 `![](…)` 字面 | 同上,完成后才异步解析并加载图片 |
| 结束后一次性"变好看" | 完成态渲染会补齐 KaTeX / Mermaid / 图片 / 脚注 |

## 5.4 其它需要顺带确认的

- **停止生成**:点停止按钮后,已收到的文字应保留(不会整段消失);
- **工具调用**:若回答过程中出现"正在调用 XX…"状态条,结束后应自动消失;
- **超长回答**:粘贴一段很长的回答(>2 万字符的单段)不应导致界面卡死(该段会退化为纯文本,属已知限制);
- **代码高亮**:本期**未实现**,代码块只有语言标签与底色——这是预期结果,不是缺陷;
- **主题切换**:切到深色主题后,重开浮窗,已有的 Mermaid 图与高亮底色应跟随主题;
- **关闭再打开浮窗**:图表应重新渲染出来(不应只剩下源码)。
